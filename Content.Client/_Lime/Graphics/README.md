# Свечение Lime Station

Новая реализация находится в `LimeLampBloomComponent`, `LimeLampBloomSystem`,
`LimeLampBloomOverlay` и `lamp_halo.swsl`. Это локальные ореолы источников,
без заимствованного дерева Sunrise, копирования экрана и многоступенчатого размытия.
Новый код распространяется по корневой MIT-лицензии; импортированные изображения
сохраняют собственные лицензии и атрибуцию.

`maskSprite` определяет светящееся ядро, `maskScale` — его размер,
`maskOffset` — центр в локальных координатах сущности. `haloRadius` задаёт
профиль ореола с ограниченной шириной до 0,35 метра. Дальность и энергия
игрового света не изменяются. Цвет берётся из текущего PointLight.

Декоративные слои с `LimeEmissiveBloom` получают ореол только при видимом слое.
Это не автоматическое размытие всех светлых пикселей экрана.
Настройки: `lime.light_bloom_enabled` и `lime.light_bloom_strength` (0–1).
Отключение убирает оверлей. Ореолы рисуются до FOV, не поверх затемнённых стен.

Локальный снимок до замены: `refs/lime-backups/pre-bloom-rewrite-20260916`,
`5857737b2580a25640e43651b07b9877200d3dd0`. Он содержит прежнюю ограниченную
реализацию и не предназначен для публикации. Для сравнения открывайте его
в отдельном рабочем дереве; не применяйте сброс поверх новых несохранённых изменений.

Ручная приёмка: трубки, маленькие лампы, столбы, аварийные лампы и стробоскопы;
включение/выключение питания, цвета тревоги, поворот и масштаб камеры,
лампы за стеной, сохранение и сброс пользовательских настроек.
