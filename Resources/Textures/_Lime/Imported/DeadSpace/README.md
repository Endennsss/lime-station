# Графика Dead Space для Lime Station

Источник: [dead-space-server/dead-space-14](https://github.com/dead-space-server/dead-space-14),
коммит [9d9a83655c6d59e655fa6a4ba6cca154d4349cc2](https://github.com/dead-space-server/dead-space-14/tree/9d9a83655c6d59e655fa6a4ba6cca154d4349cc2/Resources/Textures).

Подключены 612 явно лицензированных RSI-наборов в 330 файлах прототипов:
42 дверных/шлюзовых, 167 предметных, 294 одежды, 61 других конструкций,
9 энергетики, 8 окон, 5 стен, 1 светильник и 25 прочих наборов.
Скопированы только используемые ресурсы, без отдельной неподключённой библиотеки.
Корпуса обычных и стеклянных шлюзов, анимации и эффекты адаптированы под
односторонний формат источника. Декоративные состояния, отсутствующие в исходнике,
сохраняют явный путь к совместимой ранее используемой графике.
Код, игровые компоненты, механики и прототипы Dead Space не импортированы.

## Разрешение на графику и авторство

Общая LICENSE.TXT Dead Space ограничивает использование его билда, но содержит
отдельное исключение для элементов с индивидуальными лицензиями. Этот импорт
содержит только такие элементы с явным разрешающим объявлением в метаданных:
589 наборов CC-BY-SA-3.0, 2 CC-BY-SA-4.0 и 21 CC0-1.0.
111 наборов с собственными ограничительными условиями Dead Space исключены;
также исключены NC, неясное авторство, выявленные проблемы файлов и франшиз.
Общая лицензия проекта не подменяется и не считается разрешением на его закрытые элементы.
Список исключений находится в `import_manifest.json`.

Оригинальные PNG, `meta.json` и `.license` сохранены без изменения байтов.
Авторство, прежние изменения и происхождение остаются в `copyright`/`source`;
их нельзя удалять или подменять авторством Lime Station. Например, обычные шлюзы
имеют указанное в метаданных происхождение из TauCetiClassic.
Перенос не означает одобрения Lime Station авторами графики.
Полные тексты индивидуальных лицензий находятся в `LICENSES/`.
При распространении сохраняйте этот документ, реестр, лицензии и исходные метаданные.
При переработке CC-BY-SA-графики отмечайте изменения и соблюдайте ShareAlike
для производных изображений. Лицензия кода Lime Station не заменяет лицензию графики.
Опубликованные метаданные не доказывают полную цепочку прав первоначального автора;
обоснованные обращения правообладателей требуют отдельной проверки.

Реестр фиксирует коммит, лицензии, авторство, исходные пути и SHA-256 файлов.
Статистика сопоставленных путей включает потенциальные привязки; реально подключены
только перечисленные выше наборы. Неиспользуемые остатки прошлых импортов очищены
с сохранением истории Git и резервной копии вне репозитория.

```powershell
node Tools/_Lime/import_goob_textures.mjs . --verify --deadspace
node Tools/_Lime/import_goob_textures.mjs . --verify-index --deadspace
```
